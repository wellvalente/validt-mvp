# Validt — MVP

Mockup da plataforma **Validt Consultoria e Treinamentos**: site institucional + catálogo de cursos + área do aluno (simulado).

## Como rodar localmente

```bash
cd "site validt"
python -m http.server 8770
```

Abra: http://127.0.0.1:8770/

## O que tem neste MVP

- Home institucional (quem somos, instrutores, consultores)
- Catálogo, ficha de curso, mentoria, contato
- Login / checkout simulados (localStorage)
- Área do aluno (cursos, favoritos, certificados, contratos, perfil)
- Identidade visual do Manual de Marca Validt

## Pastas

| Pasta | Conteúdo |
|-------|----------|
| `site validt/` | Aplicação web do MVP |
| `manual/` | Manual de marca e logos |

## Observações

- Pagamentos e autenticação são **mock** — não há backend.
- Conteúdo de cursos e equipe são placeholders para demonstração.
